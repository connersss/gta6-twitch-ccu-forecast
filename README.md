Forecasts Twitch concurrent viewers in the Grand Theft Auto VI category for each hour 2..24 of release day, given only hour 1's print, using a kernel-weighted quantile model over comparable launches. It beats the persistence baseline by 56% in leave-one-out cross-validation on 37 comparable launches.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
